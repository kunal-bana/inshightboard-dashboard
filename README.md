# Role-Based Admin Dashboard

A professional admin dashboard built using **React**, **Redux Toolkit**, **MSW**, and **Material UI** with full role-based access control.

## 🔑 Features
- Role-based authentication (Admin / Manager / Employee)
- Protected routes
- MSW-powered mock APIs
- Dynamic dashboard metrics
- User management with admin-only delete
- Responsive UI with Material UI
- Centralized permission handling

## 🧑 Roles & Permissions
| Role | Access |
|----|------|
| Admin | Full access + delete users |
| Manager | Full access (read-only) |
| Employee | Limited access |

## 🛠 Tech Stack
- React + TypeScript
- Redux Toolkit
- MSW (Mock Service Worker)
- Material UI
- AG Grid
- Recharts
